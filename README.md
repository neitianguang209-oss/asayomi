# あさよみ

毎朝の「今日の雑学5選」と「今日のニュース8選」を、1つのアプリで読むための自分用PWAです。
上のバーで 雑学 ／ ニュース を切り替えます。

公開先: https://neitianguang209-oss.github.io/asayomi/

## できること

- **雑学**: 大カード／2枚並びの一覧 → 記事（ひとことで言うと・本文・会話で使える一言）。これまでの雑学は日付ごと・ジャンルごとに見返せます。
- **ニュース**: トップ／ランキング／世界・日本・AI／決算。記事には用語メモと「暮らしに効く」。
- **流れ**: 同じ話題のニュースを日付をまたいで時系列でつなぎます（記事の中の「この話題の流れ」からも開けます）。
- **言葉を調べる**: ニュースの本文で言葉を長押しすると、その言葉のシートが出ます。用語メモと Wikipedia の冒頭で意味がわかり、関連する言葉へ移ったり、この言葉が出てくる過去の記事を見たり、Google・最新ニュース・Wikipedia・Claude へ飛んだりできます。青い言葉（用語）はタップでも開きます。
- **用語帳**: ニュースの用語メモがたまっていきます。タップで同じシートが開き、復習に入れる・思考メモへ送るもここから。
- **復習**: 読んだ雑学が次の日から自動でクイズに出ます（1日→2日→5日→12日→30日→90日と間隔が伸びる）。用語は「復習に入れる」を押したものだけ。
- **さがす**: 雑学・ニュース・用語を全期間まとめて検索。保存した記事とジャンル別の一覧もここ。
- **つなぐ**: 記事の下のボタンで、思考メモ（要約とリンクを「知識」タグで保存）と Google ToDo（「To Doリスト」へ）に送れます。
- **きろく**: 連続して開いた日数、読んだ本数、覚えた数。日付の丸を押すとカレンダーで過去の日へ。

## しくみ

- 中身を作るのは Claude の定期タスク（毎朝7時）。作った雑学とニュースを Supabase の関数 `asayomi_publish` で入れます。指示文の控えは手元の `tasks/` フォルダにあります（個人的な内容を含むので、公開リポジトリには入れていません）。
- アプリは Supabase から読み、端末（IndexedDB）に写しを持ちます。開けばすぐ出て、圏外でも読めます。
- 既読・保存・復習カード・設定は、端末で書いて1件ずつクラウドへ同期します（`asayomi_state_sync`）。端末を替えても、開けば戻ります。
- Supabase はほかの自作アプリと同じプロジェクト（`gzayrjlhruhvklsidraw`）。表と関数は `supabase/schema.sql`。
- 週1回の全体バックアップ（`~/.claude/backup-supabase.ps1`）に自動で含まれます。

| 表 | 中身 |
|---|---|
| `asayomi_days` | 1日ごとの情報（あいさつ・今日のひとこと／一言リード・ランキング・決算コーナー） |
| `asayomi_items` | 記事1本ずつ（本文とイラスト） |
| `asayomi_state` | 既読・保存・復習カード・設定 |

## 手元で動かす

```
powershell -ExecutionPolicy Bypass -File serve.ps1
```

http://localhost:5511 で開きます。ビルドは不要です（素の JavaScript）。

## 直して公開するとき

1. **`sw.js` の `CACHE_NAME` の番号を1つ上げる**（上げないと古い画面が出続けます）
2. `src/config.js` の `VERSION` も上げる
3. `git add -A && git commit -m "…" && git push`

## フォルダ

- `src/` アプリ本体（`main.js` 起動と画面の行き来、`store.js` 保存と同期、`trivia.js` `news.js` `review.js` `search.js` `me.js` 各画面、`lookup.js` 長押しで言葉を調べるシート）
- `css/app.css` 見た目（雑学は `.tv`、ニュースは `.nw` の中に、それぞれ元のページの見た目を引き継いでいます）
- `icons/` アイコン（`icon.svg` を `render-icons.ps1` で各サイズに）
- `tools/` 過去分を取り込んだときの作業用（アプリ本体からは使いません）
